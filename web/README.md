# Dashboard

Dashboard Next.js com cliente WebSocket, reconexão, histórico local e filtro por canal.

```sh
export PATH="$HOME/.nvm/versions/node/v24.22.0/bin:$PATH" # se o Node do sistema estiver quebrado
npm install
npm run dev
```

Abra `http://localhost:3000` depois de iniciar o servidor.

Para iniciar pelo diretório raiz, use `./scripts/start-dashboard.sh`.
